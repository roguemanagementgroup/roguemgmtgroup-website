# RogueOS

Deterministic AI governance. Evidentiary autonomous systems.

RogueOS is a deterministic, locally executing governance framework for autonomous agents. Every agent action is logged before it happens, provable against policy, and replayable bit for bit. The guarantee survives network loss, cloud outage, host compromise, and adversarial review.

## Provenance
Architecture first authored and filed December 2025. USPTO provisional applications 63/828,137 and 63/864,057.

## Repository
The public site for Rogue Management Group LLC and the RogueOS framework. Built as a single deployable page with no build step. Deployed via Netlify from this repository.

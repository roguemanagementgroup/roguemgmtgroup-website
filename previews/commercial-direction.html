  • Current workflow map and a proposed design.
  • Data, access, and human approval requirements.
  • Tool options with cost assumptions and tradeoffs.
  • Pilot scope with measurable acceptance criteria.
  • Risks, fallback procedure, and a go / no-go recommendation.

Includes one workflow, one discovery session, a written report, and a review meeting. Software fees and implementation are separate. Final scope is agreed before booking.

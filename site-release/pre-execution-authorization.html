Technical Architecture

Pre-Execution Authorization for AI Agents

A capable AI model can propose a tool call. The model's proposal is not itself authority to invoke an external system. Builder's Permit describes an independent authorization boundary between planning and execution.

1. Propose

Describe the intended action, destination, data scope and human principal.

2. Permit

Check identity, allowed resources, action type, time limit and policy before tool access.

3. Record and execute

Record an authorization decision prior to a side effect and allow only a bounded action.

Revocation and evidence

Permit expiry and withdrawal are separate runtime decisions. Logs and replay artifacts should support post-incident review. These statements describe the published RMG architecture, not independently certified production conformance.
